# 深蓝潜航 · 2D 水肺潜水模拟

原生 Canvas 2D 单文件网页游戏，无外部依赖，浏览器直接打开 `水肺潜水模拟.html` 即可游玩。

## 玩法

- **W / S / ↑ ↓**：踢水升降
- **A / D / ← →**：水平游动
- **空格**：按住保持 BCD 浮力，缓慢上浮；松手缓慢下沉
- **P / Esc**：暂停 / 继续

离开水面沿珊瑚礁下潜，收集贝壳、珍珠与宝箱；避开水母蜇刺与海床碰撞，在气量耗尽前返回水面。结算页记录最大深度、水下时长与宝物数量并给出评级。

## 耗气模型

耗气速率随环境压力与游动强度倍增：

- 环境压力 = 1 + 深度 / 10（bar，每下潜 10 m 增加 1 bar）
- 强度系数 = 0.55 + 0.9 ×（当前速度 / 最大速度）
- 耗气 = 基础耗气 × 压力 × 强度

潜水电脑表实时显示深度、环境压力、耗气速率（%/min）与按当前速率推算的预计剩余时间。

## 技术说明

- 单文件 HTML，内联 CSS / JS，无构建工具、无外部图片素材（场景全部程序绘制）
- Web Audio 合成环境水声与拾取 / 受击音效，右上角可静音；音频在首次点击后初始化
- 适配键盘与触屏粗指针设备
